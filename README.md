# Food - order management Application
# Tech stack used - React.js, Redux toolkit, Tailwind css, Node.js, express.js
# Steps to run -
# clone the repo -
# copy env.example in both folder client and server and create new file .env in both client and server. Copy everything from env.example file.
# do npm install in both client and server seperately and do npm run dev sepretely application will run locally.
